# ModularMagic / 魔法装配

nulladev 开发的 Minecraft 1.21.1 / NeoForge 模组。Java 包名与 Maven group 为
`cn.nulladev.modularmagic`，游戏内注册 ID 使用 `modularmagic:`。
L2Magic 3.0.6、Patchouli 和 Jade 15.10.6（NeoForge 1.21.1）是必需前置，GlimmeringTales 不参与编译或运行。

当前实现的是可实际操作的法术装配原型：节点物品、法术编写台、树形编辑 GUI、
成型法术核心与未成形法术核心，以及可容纳九颗核心并实际施法的装配法杖。
已接入生存与冒险模式的魔力、专注扣费，以及基础以太生产、储存和传输；创造模式免除施法消耗。研究、主动逆转生产和世界观流程尚未实现。

## 在游戏里使用

1. 从“模块化魔法”创造模式分页取得法术编写台、一颗法术核心和节点宝石。
2. 放置并右键打开编写台，将“法术核心：瞬发 / 蓄力 / 持续”放入右上角核心槽。
3. 拿起背包里的宝石，左键点击画布上同类型的空槽。每次只装入一枚真实物品。
4. 左键选择已有节点，在右侧编辑参数，点击“应用参数”。滚动右侧面板查看其余字段。
5. 点击“取出核心”。通过引擎校验会获得成型法术核心；缺少节点或参数有误时获得
   未成形法术核心。将任一种核心放回输入槽即可继续编辑，结构、参数与节点物品全部保留。

最小示例：**法术核心：瞬发 → 法术节点：自身位置 + 法术节点：声音**。默认参数即可通过校验。
把成型核心装入装配法杖，右键即可执行该法术。

- 左键选择节点；持有宝石时左键匹配空槽装入；右键取出叶节点。
- 有子节点的节点必须先取出全部子节点，悬停可查看锁定说明。
- 画布中的根核心始终不能右键取出，只能整体取走。内部没有任何子节点时仍为对应类型的
  法术核心，保留图标等参数；只有非空但不完整的结构才保存为未成形法术核心。
- 拖动画布空白或按住鼠标中键平移；滚轮以鼠标位置为中心缩放。
- 列表保持“已占用节点 + 一个尾部空入口”，移除成员后顺序压紧，其他节点身份不变。
- 取出核心和关闭界面都会应用尚未提交的文本。关闭后核心留在编写台内，重新打开可继续编辑，
  区块卸载和存档重载也会保留。只有主动取出或拆除编写台才会移出核心；拆台时掉落完整核心。
- 同一张编写台同一时间仅供一人编辑，避免多人重复取走同一份节点。
- 节点宝石本身不保存参数，取出后恢复为可堆叠的普通物品。
- 右侧优先展示主要参数，点击“⋯”展开更多参数。可选字段留空采用引擎默认值。
  表达式直接输入文本；布尔值为 `true` / `false`，枚举使用大写，复合字段输入原生 JSON。
  错误详情悬停核心旁的状态按钮查看。左侧全高画布默认缩放 65%，最低可缩至 20%。
- 图标、物品、方块与状态效果字段提供参考槽：拿起相应物品后左键点击取样，不消耗物品。
  药水读取首个状态效果；右键清空参考值，旁边仍可手填 ID 或方块状态 JSON。
- 操作说明位于右上角 `i` 图标的悬停提示中；颜色和 tooltip 说明节点分类，名称使用
  “法术节点：循环”等道具名称。引擎类型 ID 仅在 F3+H 高级提示中显示。

## 装配法杖

从创造分页取得装配法杖，**潜行＋右键**打开九格核心仓，像普通背包一样放入或取出核心。
关闭仓库后核心保存在法杖内，选中状态和内容均随物品存档。仓库打开期间不能移动法杖本身。
核心仓总文档数据上限为 512 KiB。

持杖时沿用 L2ItemSelector 的切换方式和选择显示（默认方向键上／下，具体以控制设置为准），
切换只改变当前核心，不替换或消耗法杖中的其他核心。显示图标使用各法术根设置的图标。
普通右键施放瞬发法术；持续型按住施放；蓄力型松开时施放，`TickUsing` 记录蓄力刻数。
未成形核心可以收纳，但必须通过校验才能施放。

`CastCosts.setHandler(...)` 提供服务端资源接口，在法术效果发生前调用，返回 false 可以拒绝施法。
此兼容钩子默认允许施法；随后由内置计费处理魔力与专注。法术核心本身不会因施法而消耗。
现已加入 `ManaStorage` 物品接口与基础/扩容/终极/创造四档魔力容器，默认有限容量为 100K/1M/10M，创造容器无限。
每档仅一个物品，空满是储量状态；魔力保存在物品中，不存在玩家魔力池或自然回魔。四档稀有度依次为普通、罕见、稀有、史诗。
原法杖注册 ID `core_wand` 保留，名称改为初学者法杖，提供默认 1/1 的法力与专注倍率；
新增创造法杖固定为 0/0。生存施法先从容器预留有限预算，按实际执行结算，未用部分退回原容器。
容量与初学者倍率使用 NeoForge 原生 `modularmagic-server.toml`，可在世界的 serverconfig 中覆盖；
该 SERVER 配置由 NeoForge 同步，创造法杖倍率固定为零。
每种节点的魔力与专注公式、范围和执行上限由同目录的 `modularmagic-costs.toml` 控制。
魔力采用放大 1000 倍的计量单位；配置中的魔力公式保持归一化基值，输出统一乘 1000。
后续平衡迭代只更改设置的默认值，不再通过自动迁移覆盖已有配置。
默认专注为 `5 + 10C + 0.625C²`，C 是汇总后的结构复杂度；纯装饰结构只打折复杂度，固定 5 点不打折。
根节点配置公式保持归一化基值，最后统一乘 2.5；上限、恢复及存量/负债也按相同比例换算，施法次数与恢复时长不变。
魔力在乘法杖倍率后按整次施法累计向上取整，核心报价与 HUD 显示整数；粒子费用先合计再取整。
内置法术预算支持粒子 Age 与相关随机比值，默认执行/特效上限兼容全部 28 个示例。
纯特效子树合并为一次客户端同步，服务端仍按实际执行累计费用；执行上限由服务端配置决定。
常量费用在施法启动时缓存，纯特效控制结构不再逐粒子反射重建；客户端每 tick 默认最多创建 2048 个法术粒子，可由 `visuals.particlesPerTick` 调整。
专注负值用红色负债条显示，偿还后再恢复到上限；恢复条平滑插值不参与服务端结算。
`modularmagic-server.toml` 的 `refunds.unusedManaRefundRatio` 控制打空后未用预留的返还比例，默认 0.5。
默认 `refunds.onlyOnCompleteMiss=true`：有效目标尝试、纯特效、方块法术及未启动效果的取消均全退未用预留；设置为 false 则所有已启动施法的未用预留都按比例返还。
比例在施法启动时固定；返还向下取整，实际消耗仍是整数，重复结束不会重复返还。
创造分类提供普通三档容器的空、满状态，创造容器只提供无限状态；不注册旧分离物品。
成型核心 tooltip 显示基础魔力消耗和基础专注消耗，代入保存的常量、局部变量、循环索引、
选区与效果参数；不再显示动态占位文字或底部说明。基础报价按单目标、倍率 1 计算，
真正依赖运行时目标/位置/随机结果的附加费用不混入固定基础值；实际扣费由服务端执行。
法杖 tooltip 显示两种倍率。
主手或副手持杖时，HUD 汇总主背包、快捷栏和副手容器，显示总魔力与玩家专注。
专注采用持久化附件、服务端恢复与同步，默认上限 100、每秒恢复 10，可配置；从 0 回满约需 10 秒，负债偿还时间另算。
旧配置上限与恢复速度自动换算 2.5 倍；老的默认 40/8 会先采用 10 秒恢复平衡，再迁移为 100/10。玩家存量和负债也只迁移一次，熔断状态保留。打空、魔力返还与取消后续效果均不会返还已扣专注。
一次有限法术可以透支专注；透支后直到回满都不能开始新法术，已付费的延迟与弹体继续完成。
自定义程序通过独立的运行时编译缓存和视觉数据包执行；弹体附带分段程序数据以支持网络与存档。
少量兼容 Mixin 仅为 MM 自定义程序解析弹体、同步节点和动态贴图，L2Magic 原源码未修改。

目前节点从创造模式取得，未加入研究或节点合成流程。编写台可用工作台与书与笔无序合成。
Patchouli 的“装配指南”只介绍当前操作，不包含虚构层内容。
手册首页分为入门教程、工具与核心、节点图鉴三个分类。全部 100 种装配物品集中在节点图鉴中，
每种介绍用途、子节点类型与数量、必填或可选状态，以及可编辑参数。
从零教程用声音法术逐步演示装配、校验和法杖施放；编写台、法杖、成型与未成形核心另有独立页面。
将装配指南放在快捷栏，悬停对应物品并长按 Ctrl，可通过帕秋莉原生功能打开其介绍；
若帕秋莉设置改用 Shift，则遵循该设置。物品 tooltip 保留状态信息，操作说明集中在手册。
中英文条目均由节点模板与用途说明生成，
新增“专注与魔力怎么算”一章，每种节点另有默认魔力与专注页。
这些页面面向玩家介绍实际结算规则与默认价格；参考费用集中在
`scripts/node-cost-reference.ps1`，通用计算讲解在 `scripts/generate-cost-chapter.ps1`。
运行 `./scripts/generate-node-assets.ps1` 会同时更新节点名称、模型与手册目录。

另有“模块化魔法：内置法术”创造分页，提供 L2Magic 全部 **28 个示例法术**的成型核心，
可直接放进编写台查看、拆装与修改。通过引擎 Codec 从当前注册表导入，保留原法术参数和效果，
并将引用的弹体配置展开为可编辑节点；兼容数据包对原法术的覆盖。
`BuiltinSpells.create(id, registries)` 供创造分页和未来战利品生成共用，ID 与 L2Magic 示例一致。
名称使用 MM 独立的完整中英文词条。L2Magic 创造分页隐藏由 MM 内部入口自动生成的法杖，
装配法杖只放在 MM 分页。本次尚未修改野生宝箱战利品表。

## 节点覆盖与数据

共 **100 种装配物品**，包括 97 种法术节点和 3 种施法类型的法术核心：L2Magic 的
9 类、88 种注册节点，另加表达式条件、7 种起点和弹体配置。显式模板是
`src/main/resources/data/modularmagic/node_templates.json`。
同类同色，种类通过不同刻纹区别；初稿模型使用原版方块贴图，可运行
`./scripts/generate-node-assets.ps1` 重新生成物品模型与中英文名称。

核心通过 1.21 的 `minecraft:custom_data` 组件保存有版本号的 MM 草稿，允许必需槽缺失、
表达式未写完等情况。成型时额外保存 L2Magic 原生法术 JSON 和本地弹体配置 JSON。
校验使用 L2Magic 的 Codec、注册表与表达式作用域规则，收集其子节点错误诊断，并补充
其遗漏的表达式操作数检查。
弹体配置在编译期间使用独立的临时注册表，不修改前置或世界注册表。

服务端负责物品转移、类型和父节点锁定检查。请求携带文档版本；过期请求拒绝并重新同步。
草稿限制为 256 个节点、24 层、每列表 64 个成员，单个参数 2048 字符。
随机变量节点最多声明 64 个变量，避免编辑时展开过大的变量集合。

## 以太生产与供能原型

新增以太扰乱器、基础/扩容/终极/创造以太储槽与发射器、以太凝结器、以太结晶室、共鸣器、个人供能锚、世界锚和创造以太发生器。
现有 37 张独立的 16×16 像素贴图，由 `scripts/generate-prototype-textures.mjs` 重复生成。以太碎片为蓝白晶体，随身容器为罐状器物；工具、法杖、核心、编写台、节点配色与能源设备均使用自己的贴图。创造档保留正常金属、外壳与以太颜色，只在徽记、束环等局部使用紫黑棋盘格。
储槽均渲染液面及浸入其中的充能物品；创造档提供无限以太且没有合成表。结晶室围绕中央下界之星呈现固态晶簇。
发射器的头部随绑定目标的水平及垂直方向转动。
主动逆转生产装置尚未加入。

先将创造以太发生器放在储槽旁，手持魔力容器右键储槽即可充能，潜行空手右键取回。
使用调谐器依次点击发射器和接收端建立射流，四档默认射程分别为 8/16/24/64 格，经过的方块会阻挡射流。
根共鸣器贴邻有以太的储槽放置。用调谐器依次点击上游与下游，可连接树状主网；每个共鸣器只有一个上游，可以分出多个下游，绑定会检查回环、所有权及距离。普通设备也需明确绑定供能端，仍可接收原有的相邻/射流供能。
共鸣器合成为空壳，空载带宽与有效范围均为零。装入紫水晶后启用，默认带宽为 `紫水晶枚数×100`/秒，第一枚 100/秒，64 枚正好 6.4K/秒。潜行批量安装，潜行空手取回；取空后停止供能。
启用后的基础无损/最远半径为 16/32 格，再按每枚增加 2/4 格，因此第一枚无损 18 格、最远 36 格，满配无损 144 格、最远 288 格。超出无损半径后每格损失发送量的 5%，上限 75%；设备及随身接收器共享发送带宽。基础范围、成长值、带宽和损耗公式均可配置。
随身接收器绑定整张主网，在任一已连接支路覆盖内给背包/副手容器充电。上游卸载、被替换、改频或断开时，失联支路不再回应原主网接收器；拓扑查询不加载区块。覆盖重叠时按实际剩余吞吐选择供能源，避免选中积蓄多但已用完带宽的节点。
个人供能锚配方需要晶化以太碎片与钻石，提供中后期的同世界远程补给；跨界需制作并安装「定界之眼」，配方含龙息、紫颂材料、末影之眼、晶化碎片与下界合金碎片。
世界锚空手右键启停，潜行使用调谐器切换 1/9 个区块；缺能或所有者离线一分钟后停止。
服务器重启后需要回到基地，让保存的世界锚重新加载并启动。

扰乱器放在中央工作水格下，两侧各有一个水源，阻止中央流动水生成水源并缓慢收集以太。
空手触摸扰乱器或有以太供应的凝结器，扣除 200 以太取出一枚碎片，潜行可一次取出至多 16 枚；默认 100 tick 后消散，请预先准备工作台和材料。
凝结器沿用扰乱器的末影珍珠干涉结构，由扰乱器配合铜、玻璃制作，不需要水源；寿命从取出时开始，储槽不再提供碎片。
不稳定碎片的物品提示和手持 HUD 都显示实时剩余 tick；主手、副手均支持，期限到达即消失。
两种碎片的 tooltip 均显示实际封存量，不显示结晶加工费。对有空间的普通储槽右键可回存；过期碎片无效，加工费不返还。
以太结晶室可用原版材料与下界之星直接制作，连接供能后每秒最多产出四枚稳定碎片，每枚消耗 400 以太。
产物可手动领取或由漏斗取出；结晶室不为物品充能，也不会自行产能。拆除储槽会散失内部以太，充能物品单独掉落。
全部新设备的双语操作说明在手册「以太的流向」中。章节以观察记录和实际操作描述机制；世界锚重启后的限制用沉寂与苏醒解释，仍明确需要返回锚旁。
服务端参数位于 `config/modularmagic-energy.toml`。碎片含量与寿命、结晶加工费与周期、各设备缓存与带宽、扰乱器产能、射流速度与距离损耗、共鸣扩容与距离损耗、远程额外费用、世界锚维护/启动费与离线宽限均由原生配置决定。
随身容器容量由 `config/modularmagic-server.toml` 的 `containers` 控制。所有文档数字均为默认值；配置文件中的数量填写完整数字，K/M/B 仅用于显示。网络充能不会占用施法退款预留容量。
所有以太/魔力数量统一使用 K（千）、M（百万）、B（十亿），包括物品提示、HUD、Jade、交互提示和手册；内部精度和结算方式不变。
当前处于开发阶段，设备注册 ID 直接采用新命名，不提供旧版存档迁移。

Jade 在客户端和服务器上都是必需前置，开发环境通过 Modrinth Maven 自动引入，并未打入发布 JAR。
看向能源设备可查看储量进度条、工作状态和充能容器；按住 Shift 查看设备带宽、射程、目标、
频道、跨维度升级和世界锚维护费。看向掉落的魔力容器、碎片、法杖、法术核心和储槽物品，
也可查看其魔力相关信息。原先调谐器独占的检查框已由 Jade 取代，持杖补给 HUD 仍保留。
所有查询只读，不会领取退款、取走以太或启动设备。

手册「以太的流向」包含 20 个独立物品条目与七页供能教程，节点、资源和工具章节同步清理了开发者措辞。

使用 **JDK 21**、项目自带的 **Gradle 8.8 Wrapper**。IDEA 中重新加载 Gradle，并将
Gradle JVM 设为 JDK 21。

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTestServer
.\gradlew.bat runClient
```

输出为 `build/libs/modularmagic-0.1.0.jar`。安装时需另外安装 L2Magic、Patchouli、Jade 及所需的
L2 库，它们均未打入本模组。Curios 使用 IllusiveC4 Maven。
已有有效的 1.21.1 缓存时，构建配置优先复用 Minecraft 元数据、游戏 JAR 和映射，避免
IDE 每次启动都重下 Mojang 版本清单；Maven 依赖仍正常联网。首次下载或缓存缺失时走
正常下载流程。需要主动更新元数据时使用 `-PrefreshMinecraftMetadata=true`，或
`--refresh-dependencies`。本机代理放在被 Git 忽略的 `gradle-local.properties`，与 IDEA HTTP 代理独立；当前本机设置仍为 `127.0.0.1:7890`。该文件使用 `systemProp.http.proxyHost`、`systemProp.http.proxyPort`、HTTPS 对应项及 `systemProp.http.nonProxyHosts`，由 `settings.gradle` 在解析插件前加载。未创建此文件时不强制使用代理；项目版本等共享设置继续放在 `gradle.properties`。

## 工程目录

- `src/main/java/cn/nulladev/modularmagic/`：本模组代码。
- `spell/`：节点模板、草稿、L2Magic 编译与校验适配。
- `menu/`、`network/`、`client/`：服务端装配会话、同步协议、实际编辑界面。
- `src/main/resources/`：独立资源、模板、语言与操作手册。
- `src/test/`：文档与约束单元测试。
- `src/gameTest/`：游戏内集成测试与客户端检查驱动；不进入发布 JAR。
- `libs/`：固定版本的本地开发依赖及源码附件，仅当前构建使用的十个库系列加入版本管理；其他本地下载的 mod JAR 被忽略。
- `reference/l2magic/`：原始上游项目参考快照，不参与构建；README、构建配置、Wrapper 等均已恢复到仓库原始版本。
- `private-design/`：Git 忽略的历史设计文档。
